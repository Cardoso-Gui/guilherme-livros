Site estático publicado pelo GitHub Pages a partir de main, na raiz.

## Modelo de vendas
Desde 5 de outubro de 2026, o site é um catálogo com sinopses e prévias gratuitas. Novas compras serão feitas na Amazon. Links oficiais adicionados em 08/10/2026: Noah — https://www.amazon.com.br/dp/B0HM9GLSB1; O Quinto Herdeiro — https://www.amazon.com.br/dp/B0HM9DHVTN. Os links abrem em nova aba com target=_blank e rel=noopener noreferrer. Labirinto Verde permanece com “Em breve na Amazon”. Não inventar ASINs nem usar busca genérica como página de compra.

## Sistema anterior
Login, cadastro, carrinho e biblioteca internos foram retirados. URLs antigas exibem orientação e contato para compras anteriores. Os registros e arquivos privados foram preservados. A função mercado-pago-checkout retorna 410 e não cria novos pedidos; webhook e status permanecem para pedidos anteriores. Não reativar o sistema antigo ao lançar livros.
